# Дастурамал барои қолабкушо (TJ)

Қолабкушо (распалубщик) дар барнома ҳар паллетаро аз рехтан қабул мекунад ва маҳсулоти сифатнок ва бракро қайд мекунад. Паллетаро ҳамеша қисме қабул мекунад, ки он ба онҷо омадааст. Дастурамал барои ҳама сехҳо яктост. Номи тугмаҳо ба русӣ, дар қавс — тарҷума.

## Пеш аз смена ва воридшавӣ

- Телефон ё ТСД заряд дорад ва ба Wi-Fi-и сех пайваст аст.
- PIN-коди шахсиро ба ҳеҷ кас нагӯед: ҳамаи амалҳо ба номи шумо сабт мешаванд.
- Паллетаи бе тамға — фавран ба усто гӯед.

Воридшавӣ (як бор, телефон дар ёд нигоҳ медорад):

1. Барномаро кушоед. Бо тугмаи «Цех ▾» (Сех) дар боло сехи худро интихоб кунед.
2. PIN-ро дароред → «Войти» (Ворид шудан).
3. «Мой участок» (Қисми ман) — **«Распалубка»** (Қолабкушоӣ). Дар ТСД аломати **«Это ТСД со встроенным сканером»** (Ин ТСД бо сканери дарунӣ) гузоред. «Готово» (Тайёр).

Тугмаи ⟳ дар боло маълумотро нав мекунад. Иваз кардани корбар — дар боло ба номи худ пахш кунед → «Выйти» (Баромадан).

## Скан кардан

- **Телефон:** дар экрани асосӣ «📷 Сканировать» (Скан кардан) → камераро ба QR-код рост кунед.
- **ТСД:** **тугмаи норинҷӣ**-и сканерро пахш кунед ва нури сурхро ба QR-код рост кунед. Тугмаи экранро пахш накунед.
- Дар болои экрани асосии ТСД: сабз **«Сканер готов»** (Сканер тайёр) — метавонед скан кунед; зард **«Коснитесь экрана»** (Ба экран даст расонед) — як бор ба ҳар ҷои экран даст расонед.
- Дар карточкаи паллета фавран паллетаи навбатиро скан кардан мумкин — ба экрани асосӣ баргаштан лозим нест.
- Агар тамға скан нашавад — рақами онро дар майдони экрани асосӣ дароред → «Найти» (Ёфтан).

## Қабули паллета, брак, аз нав чидан

**Қабул аз рехтан** (баъд аз кушодани қолаб ва шумориш):

1. Паллетаро скан кунед. Дар карточка артикул ва рангро санҷед.
2. Бахши «Переместить» (Интиқол) → тугмаи сабз **«✓ Принять на «Распалубка»»** (Ба қолабкушоӣ қабул кардан).
3. «Годных принято, шт» (Сифатноки қабулшуда, дона): агар ҳама саломат бошад — иваз накунед. Агар браки рехтан бошад (пурра рехта нашуда, сӯрах, кафидагӣ) — танҳо сифатнокҳоро нависед ва сабабро интихоб кунед. Ин брак ба рехтан навишта мешавад.
4. «Подтвердить перемещение» (Интиқолро тасдиқ кардан) → паёми сабзро интизор шавед.

Баъд паллетаро қисми арракунӣ қабул мекунад — онро фиристодан лозим нест.

**Брак дар қолабкушоӣ** (ҳангоми баровардан шикаст, афтод): паллета дар «Распалубка» → бахши «Брак» (Брак) → миқдор, сабаб, «Списать» (Аз ҳисоб баровардан) ё «На доработку» (Барои коркарди такрорӣ) → «Провести брак» (Бракро гузаронидан). Бракро фавран аз паллета гиред.

**Аз нав чидан** ба паллетаҳои дигар (як артикул ва ранг): бахши «Слияние» (Якҷоякунӣ) → «Было» (Буд) — паллетаҳои кӯҳна, «Стало» (Шуд) — тамғаҳои нави тоза ва дона → «Подтвердить слияние» (Якҷоякуниро тасдиқ кардан). Тамғаҳои кӯҳнаро канда партоед.

## Ислоҳот, рӯйхат, паллетаҳои таълимӣ

**Агар дар паллета миқдор, артикул ё ранг дигар бошад, на мисли карточка:** бахши **«✎ Исправить»** (Ислоҳ кардан) → ислоҳ кунед → сабабро нависед → «Сохранить исправление» (Ислоҳро нигоҳ доштан). Агар маҳсулот аз сабаби брак кам шуда бошад — ислоҳ накунед, бракро гузаронед.

**Бекор кардани амали худ:** «🕘 Мои действия» (Амалҳои ман) → «↩ Отменить» (Бекор кардан) ё «✎ Исправить» (24 соат, то қабул кардани паллета аз ҷониби қисми навбатӣ).

**Рӯйхати «На участке» (Дар қисм):** навтаринҳо дар боло. Ранг: сабз — то 2 соат, хакистарӣ — то як шабонарӯз, норинҷӣ — зиёда аз як шабонарӯз, сурх — дер мондааст. Аввал норинҷӣ ва сурхҳоро аз қолаб бароред.

**🎓 Паллетаҳои таълимӣ** (навиштаи зард) — барои машқ, ба ҳисоб дохил намешаванд. Бо онҳо ҳамон корҳоро кардан мумкин, вале дар якҷоякунӣ бо паллетаҳои воқеӣ арастан мумкин нест.

## Хатоҳо ва чӣ бояд кард

| Чӣ мебинед | Чӣ бояд кард |
| --- | --- |
| Баъд аз скан «Залить новую паллету» (Рехтани паллетаи нав) | Рехтагар онро қайд накардааст. Ҳеҷ чизро пахш накунед — ба рехтагар ё усто гӯед. |
| Тугмаи «Принять» (Қабул кардан) нест | Паллета аллакай дар қисми шумост — такрор лозим нест. |
| «Паллета закрыта» (Паллета пӯшида аст) | Тамғаи кӯҳна (баъд аз якҷоякунӣ) — тамғаи амалкунандаро ёбед ё ба усто гӯед. |
| Дар карточка артикул нодуруст | «✎ Исправить» (Ислоҳ кардан) бо сабаб ё ба усто гӯед. |
| ТСД: баъд аз тугмаи норинҷӣ ҳеҷ чиз намешавад | Ба экран даст расонед ва такрор кунед. Ёрӣ надод — ба усто. |
| «Неверный PIN» (PIN нодуруст) | Аз нав дароред; фаромӯш кардед — усто навашро медиҳад. |
| Алоқа нест, тугма мечархад | Аз нав пахш накунед. Wi-Fi-ро санҷед, баъд паллетаро боз скан кунед. |
