# Дастурамал барои рехтагар (TJ)

Рехтагар (заливщик) дар барнома ҳар паллетаи рехташударо қайд мекунад: кадом мавқеими супориши сменаи пости худро ва чанд дона рехтааст. Дастурамал барои ҳама сехҳо яктост. Номи тугмаҳо мисли дар барнома ба русӣ навишта шудаанд, дар қавс — тарҷума.

## Пеш аз смена ва воридшавӣ

- Телефон ё ТСД (терминали сканер) заряд дорад ва ба Wi-Fi-и сех пайваст аст.
- Дар пост тамғаҳои тозаи QR ҳастанд, усто супориши сменаро дохил кардааст.
- PIN-коди шахсиро ба ҳеҷ кас нагӯед: ҳамаи амалҳо ба номи шумо сабт мешаванд.

Воридшавӣ (як бор, телефон дар ёд нигоҳ медорад):

1. Барномаро кушоед. Бо тугмаи «Цех ▾» (Сех) дар боло сехи худро интихоб кунед.
2. PIN-ро дароред → «Войти» (Ворид шудан).
3. «Мой участок» (Қисми ман) — **«Заливка»** (Рехтан). Дар ТСД аломати **«Это ТСД со встроенным сканером»** (Ин ТСД бо сканери дарунӣ) гузоред. «Готово» (Тайёр).

Тугмаи ⟳ дар боло маълумотро нав мекунад (масалан, агар усто супоришро иваз карда бошад). Иваз кардани корбар — дар боло ба номи худ пахш кунед → «Выйти» (Баромадан).

## Скан кардан

- **Телефон:** дар экрани асосӣ «📷 Сканировать» (Скан кардан) → камераро ба QR-код рост кунед.
- **ТСД:** **тугмаи норинҷӣ**-и сканерро пахш кунед ва нури сурхро ба QR-код рост кунед. Тугмаи экранро пахш накунед.
- Дар болои экрани асосии ТСД: навиштаи сабз **«Сканер готов»** (Сканер тайёр) — метавонед скан кунед; зард **«Коснитесь экрана»** (Ба экран даст расонед) — як бор ба ҳар ҷои экран даст расонед.
- Агар тамға скан нашавад — рақами онро (масалан, 200015) дар майдони экрани асосӣ дароред → «Найти» (Ёфтан).

## Рехтан

Як паллета = як тамғаи тоза = як қайд. Баъд аз рехтан фавран қайд кунед.

1. Тамғаи тозаро часпонед ва скан кунед.
2. «Залить новую паллету» (Рехтани паллетаи нав) кушода мешавад. Дар боло тугмаҳои постҳо («Пост 1», «Пост 2»…): **пости худро** пахш кунед. Телефон онро дар ёд нигоҳ медорад; «Все» (Ҳама) тамоми супоришро нишон медиҳад.
3. Мавқееро, ки рехтед, пахш кунед (артикул, ранг, фармоиш). Рецепт — тугмаи «🧪 Техкарта» (Техкарта).
4. «Штуки» (Дона) ё «Формы» (Қолаб) ро интихоб кунед ва миқдори дар ин паллетаро дароред.
5. Тугмаи сабз «Залита — поставить на «Заливка»» (Рехта шуд — ба «Рехтан» гузоштан). Паёми сабзро интизор шавед — дар он дида мешавад, ки аз нақша чанд мондааст.

**Сменаи шаб.** Шабонарӯзи корӣ соати 06:00 оғоз мешавад. Ҳама чизе, ки аз 00:00 то 06:00 рехта шуд, ба супориши дирӯза дохил мешавад — сменаи худро мисли оддӣ идома диҳед.

Иҷрои супориш аз рӯи постҳо — «📊 Отчёты» (Ҳисоботҳо) → «Задание заливки» (Супориши рехтан).

## Ислоҳот, рӯйхат, паллетаҳои таълимӣ

**Агар дар миқдор, артикул ё ранг хато кардед:** паллетаро скан кунед → бахши **«✎ Исправить»** (Ислоҳ кардан) → майдонҳоро ислоҳ кунед → сабабро нависед → «Сохранить исправление» (Ислоҳро нигоҳ доштан). Факти супориш худ аз нав ҳисоб мешавад.

**Бекор кардани амали худ:** «🕘 Мои действия» (Амалҳои ман) → «↩ Отменить» (Бекор кардан) ё «✎ Исправить». 24 соат ва то қабул кардани паллета аз ҷониби қисми навбатӣ кор мекунад.

**Рӯйхати «На участке» (Дар қисм)** дар экрани асосӣ: паллетаҳои навтарин дар боло. Ранги хат: сабз — то 2 соат, хакистарӣ — то як шабонарӯз, норинҷӣ — зиёда аз як шабонарӯз, сурх — дер мондааст (ба усто гӯед).

**🎓 Паллетаҳои таълимӣ** (навиштаи зард «УЧЕБНАЯ ПАЛЛЕТА» — паллетаи таълимӣ) — барои машқ, ба ҳисоб дохил намешаванд. Ба тамғаи таълимӣ рехтан мумкин нест — тамғаи нави тоза гиред.

## Хатоҳо ва чӣ бояд кард

| Чӣ мебинед | Чӣ бояд кард |
| --- | --- |
| Барои имрӯз супориши смена нест | Ба усто гӯед, баъд ⟳ ва аз нав скан кунед. |
| Дар рӯйхат мавқеҳои пости шумо нест | «Все» (Ҳама)-ро пахш кунед ё аз усто пурсед, мавқеъ ба кадом пост гузошта шудааст. |
| «Паллета … уже залита» (Паллета аллакай рехта шудааст) | Тамға истифода шудааст — навашро гиред. |
| «Паллета — учебная» (Паллета — таълимӣ) | Ин тамғаи кӯҳна аст — тамғаи нави тоза гиред. |
| ТСД: баъд аз тугмаи норинҷӣ ҳеҷ чиз намешавад | Ба экран даст расонед ва такрор кунед. Ёрӣ надод — ба усто. |
| «Неверный PIN» (PIN нодуруст) | Аз нав дароред; фаромӯш кардед — усто навашро медиҳад. |
| Алоқа нест, тугма мечархад | Аз нав пахш накунед. Wi-Fi-ро санҷед, баъд «Мои действия» (Амалҳои ман). |

Чизеро рехтед, ки дар супориш нест? Зери мавқеи дигар қайд накунед — бигузоред, ки усто онро ба супориш илова кунад.
