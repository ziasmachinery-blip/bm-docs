# Дастурамал барои усто (TJ)

Усто (мастер) ҳисобро дар Ҷадвали Google-и сехи худ мебарад: супориши смена аз рӯи постҳо, коргарон ва PIN, тамғаҳо, назорат ва ислоҳот. Дастурамал барои ҳама сехҳо яктост; менюи Ҷадвал «Меню Цех N» ном дорад. Номи меню ва тугмаҳо ба русӣ, дар қавс — тарҷума.

## Вазифаи усто ва навгониҳо

Роҳи паллета: Заливка (Рехтан) → Распалубка (Қолабкушоӣ) → Распиловка (Арракунӣ) → Покраска (Рангубор) → Зона набора прочности (Минтақаи мустаҳкамшавӣ) → Упаковка (Бастабандӣ) → Склад ГП (Анбори МТ). Дар ҳар қисм паллетаро коргаре қабул мекунад, ки дар онҷо кор мекунад.

Навгониҳо дар барнома ва Ҷадвал:

- **Постҳои рехтан** — дар супориши смена сутуни «Пост», рехтагар мавқеҳои пости худро мебинад.
- **Шабонарӯзи корӣ аз 06:00** — рехтан баъд аз нисфи шаб ба супориши рӯзи гузашта дохил мешавад.
- **«✎ Исправить» (Ислоҳ кардан)** — ҳар коргар дар ҳар қисм миқдор, артикул, ранг, фармоишро бо сабаб ислоҳ мекунад; бақия ва супориш аз нав ҳисоб мешаванд.
- **ТСД Mertech** — скан бо тугмаи норинҷӣ.
- **Рӯйхати «На участке» (Дар қисм)** — аввал навҳо, ранг аз рӯи вақт дар қисм.
- **Тамғаҳо дар Xprinter XP-365B** ва рақамгузории хоси сех (дар Сехи 2 рақамҳо аз PL-2000… оғоз мешаванд, то бо сехҳои дигар мос нааянд).
- **🎓 Паллетаҳои таълимӣ** — баъд аз «Начать учёт заново» (Ҳисобро аз нав оғоз кардан) паллетаҳои кӯҳна барои машқ, ба ҳисоб дохил намешаванд.

## Барнома дар телефон ва ТСД

**Телефони коргар:**

1. «Меню Цех N» → «📱 Приложение с камерой» (Барнома бо камера) — истинод ва QR-код.
2. Истинодро дар Chrome кушоед → ⋮ → «Добавить на главный экран» (Ба экрани асосӣ илова кардан).
3. Коргар «Цех ▾» (Сех)-ро интихоб мекунад, бо PIN ворид мешавад, қисмро интихоб мекунад. Қисмро санҷед — тугмаи «✓ Принять» (Қабул кардан) аз он вобаста аст.

**ТСД Mertech (як бор):**

1. Барномаи **Barcode Utility** → Function Settings → реҷаи баровард **«Simulate keystroke»** (тақлиди клавиатура), суффикс **Enter**.
2. Барномаро мисли дар телефон насб кунед.
3. Дар профил (дар боло ба ном пахш кунед) аломати **«Это ТСД со встроенным сканером»** (Ин ТСД бо сканери дарунӣ) гузоред.
4. Санҷиш: тугмаи норинҷӣ ба тамға — карточкаи паллета кушода мешавад.

**Усто дар барнома чӣ мебинад:** «📊 Отчёты» (Ҳисоботҳо) → «Задание заливки» (Супориши рехтан, бо ҷамъ аз рӯи постҳо) ва «Шт на этапах» (Дона дар марҳилаҳо); скани ҳар паллета — таърих: ки, кай, чӣ кард.

## Супориши смена: постҳо, шабонарӯзи корӣ

Кушодан: «Меню Цех N» → **«📋 Сменное задание: открыть»** (Супориши сменаро кушодан).

| Сутун | Чӣ навиштан |
| --- | --- |
| Дата (Сана) | Санаи шабонарӯзи корӣ |
| № заказа, Контрагент (№ фармоиш, Контрагент) | Аз фармоиш |
| Артикул | Аз рӯйхат интихоб кунед |
| Цвет (Ранг) | Ранг / пигмент |
| **План форм** (Нақшаи қолаб, зард) | Чанд қолаб рехтан |
| Комментарий (Шарҳ) | Ба хоҳиш |
| **Пост** (сутуни охирон) | Пост 1 / 2 / 3. **Холӣ — мавқеъро ҳама постҳо мебинанд** |

**Қоидаҳо:**

- Як сатр = фармоиш + артикул + ранг + пост. Барои тақсими мавқеъ байни постҳо ду сатр бо постҳои гуногун созед ва нақшаро тақсим кунед.
- **Шабонарӯзи корӣ соати 06:00 оғоз мешавад.** Рехтан аз 00:00 то 06:00 ба супориши рӯзи **гузашта** ҳисоб мешавад. Соат дар «Настройки» (Танзимот) → «Начало рабочих суток, ч» иваз карда мешавад.
- Номи постҳо — дар «Настройки» → «Посты заливки» (бо вергул).
- Баъд аз иваз кардани супориш ба рехтагарон гӯед, ки дар барнома **⟳**-ро пахш кунанд.
- Филтрҳои меню: «сегодня» (имрӯз), «завтра» (фардо), «все» (ҳама).
- Ба «Факт» ва «Выполнено» (Иҷро шуд) даст назанед — онҳо худ ҳисоб мешаванд.

## Назорат, ҳисоботҳо, ислоҳот

- **Факт / Выполнено** дар супориш аз рӯи скани рехтагарон худкор пур мешаванд. Рехтани бе супориш ба сатрҳои «вне задания» (берун аз супориш) меафтад — дар охири смена санҷед.
- Бақия аз рӯи қисмҳо ва дашбордҳо худ нав мешаванд. Агар рақамҳо аҷиб намоян шаванд — «Меню Цех N» → **«🔄 Пересчитать всё»** (Ҳамаро аз нав ҳисоб кардан).
- Коргарон метавонанд дар ҳар марҳила бо тугмаи **«✎ Исправить»** маълумоти паллетаро ислоҳ кунанд. Ҳар ислоҳ ба таърих бо номи коргар чун **«Инвентаризация ±»** (Инвентаризатсия) навишта мешавад — чунин сатрҳоро санҷед.
- Амали хаторо коргар худ бекор мекунад: «Мои действия» (Амалҳои ман) → бекор кардан.
- Агар паллета хато рехта шуда бошад → дар варақи «Паллеты» сатрро интихоб кунед → **«↩ Паллеты: сбросить выделенные»** (Паллетаҳои интихобшударо тоза кардан).
- Баровардани барвақт аз минтақаи мустаҳкамшавӣ — танҳо бо қарори усто.
- Агар дар сабтҳои кӯҳна рехтани шаб ба рӯзи дигар афтода бошад — **«Рабочие сутки: применить к старым записям»** (Шабонарӯзи кориро ба сабтҳои кӯҳна татбиқ кардан). Аз нав оғоз кардан мумкин, ду бор намегузаронад.

## Корбарон, тамғаҳои XP-365B, паллетаҳои таълимӣ

**Корбарон.** «Меню Цех N» → илова кардани корбар → система PIN медиҳад, онро ба коргар шахсан диҳед. PIN фаромӯш шуд — навашро диҳед. Аз кор рафт — дар сутуни «Активен» (Фаъол) **Нет** (Не) гузоред (сатрро нест накунед — таърих нигоҳ дошта мешавад).

**Тамғаҳо дар Xprinter XP-365B:**

1. «🏷 QR-этикетки: напечатать новые…» (Чопи тамғаҳои нави QR) → шумораро дароред.
2. **«🖨 Открыть для печати на XP-365B»** (Барои чоп дар XP-365B кушодан)-ро пахш кунед.
3. Дар равзанаи чоп: принтер XP-365B, андозаи кағаз = андозаи тамға (А×Б), ҳошия **не**, миқёс **100%**, колонтитулҳо **хомӯш**.
4. Андозаи тамға: «🏷 Этикетки: размер для принтера». Рақамгузории сех: «🏷 Этикетки: своя нумерация цеха».
5. Аз нав чоп кардани тамғаи вайроншуда: дар «Паллеты» сатрҳоро интихоб кунед → аз нав чоп кардан. Лавҳаҳои суроғаи анбор ҳам дар ҳамин ҷо чоп мешаванд.

**Ҳисоб аз нав ва таълим:**

- **«🧹 Начать учёт заново»** (Ҳисобро аз нав оғоз кардан) — ҳамаи маълумоти кӯҳна ба ҷадвали байгонӣ дар Google Диск мегузарад, паллетаҳои кӯҳна **таълимӣ** мешаванд (аломати «🎓 УЧЕБНАЯ», ба ҳисоб дохил намешаванд). Як бор пеш аз оғози ҳисоби нав иҷро карда мешавад.
- **«🎓 Учебные паллеты: завершить обучение»** (Таълимро анҷом додан) — вақте ки ҳама омӯхтанд, паллетаҳои таълимӣ гирифта мешаванд.
- **«🗂 Вкладки: упорядочить»** (Варақҳоро тартиб додан) — варақҳои зарурӣ дар чап, варақҳои хидматӣ пинҳон. «показать все» (ҳамаро нишон додан) — агар варақи пинҳон лозим бошад.
- Дар варақи «Настройки» дар хонаи **E11** коди сех бояд бошад (c2 барои Сехи 2, c3 барои Сехи 3). Онро иваз накунед.

## Агар чизе нодуруст шуд

| Чӣ шуд | Чӣ бояд кард |
| --- | --- |
| Дар рехтагар «Нет задания на сегодня» (Барои имрӯз супориш нест) | Санаро дар супориш санҷед (06:00-ро дар ёд доред). Бигузоред, ки ⟳ пахш кунад |
| Дар пост мавқеъ дида намешавад | Дар сутуни «Пост» пости дигар навишта шудааст. Ислоҳ кунед ё холӣ монед |
| «Нет «Шт в форме»» (Дона дар қолаб нест) | Дар рӯйхати артикулҳо барои ин артикул «Шт в форме»-ро пур кунед |
| Дар барнома алоқа нест | Wi-Fi / интернетро санҷед. Амалро баъд аз пайдо шудани алоқа такрор кунед |
| Дар «Лог\_форм» сатри «ОШИБКА» (Хато) | Матни хаторо хонед, маълумотро ислоҳ кунед, дар ҳолати зарурӣ — «🔄 Пересчитать всё» |
| «Меню Цех N» пайдо намешавад | Саҳифаи Ҷадвалро нав кунед, 10–20 сония интизор шавед |
| ТСД кодро худкор ворид намекунад | Barcode Utility → «Simulate keystroke» + суффикс Enter; дар профил аломати «Это ТСД» |
| Саҳифаи тамғаҳо — хатои 404 | Дар GitHub файли **labels.html** нест (ном ҳатман бо .html) |
| «Не указан код цеха» (Коди сех нишон дода нашудааст) | Дар варақи «Настройки» дар E11 коди сехро нависед (c2 / c3) |

> **Қоидаи асосӣ:** варақҳои «Движение», «Паллеты», «Остатки» ва сутунҳои фактро дар супориш бо даст иваз накунед. Ҳамаи ислоҳот — тавассути барнома ё меню.
