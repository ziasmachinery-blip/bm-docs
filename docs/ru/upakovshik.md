# Инструкция упаковщика (RU)

Упаковщик принимает паллету из зоны набора прочности, упаковывает, передаёт на «Склад ГП» и ставит адрес хранения. Инструкция одна для всех цехов.

## Перед сменой и вход

- Телефон или ТСД заряжен и подключён к Wi-Fi цеха.
- Есть коробки; если паллеты взвешивают — весы работают.
- На складе висят таблички с QR-кодами адресов.
- Личный PIN-код никому не сообщайте.

Вход (один раз, телефон запоминает):

1. Откройте приложение. Кнопкой «Цех ▾» вверху выберите свой цех.
2. Введите PIN → «Войти».
3. «Мой участок» — **«Упаковка»**. На ТСД поставьте галочку **«Это ТСД со встроенным сканером»**. «Готово».

Кнопка ⟳ вверху обновляет данные. Сменить пользователя — нажать на своё имя вверху → «Выйти».

## Сканирование

- **Телефон:** на главном экране «📷 Сканировать» → навести камеру на QR-код.
- **ТСД:** нажать **оранжевую кнопку** сканера и навести красный луч на QR-код. Экранную кнопку не нажимать.
- На ТСД вверху главного экрана: зелёная подсказка **«Сканер готов»** — можно сканировать; жёлтая **«Коснитесь экрана»** — коснитесь экрана один раз.
- Табличку адреса на стеллаже сканируйте так же. На главном экране она покажет, какие паллеты стоят по этому адресу.

## Приём, упаковка, склад

На каждую паллету три отметки: принять → упаковать → сдать на склад.

**1. Принять.** Скан → «Переместить» → **«✓ Принять на «Упаковка»»** → проверьте «Годных принято» (брак предыдущих участков — меньше штук и причина) → «Подтвердить перемещение».

Если вышло «⚠ Паллета в зоне набора прочности всего …» — камень ещё не готов: «Отмена». «Всё равно» — только по распоряжению мастера.

**2. Упаковать.** Откроется вкладка «📦 Упаковать». «Изделий в коробке» и «Вес изделия» уже заполнены (можно поправить). Приложение покажет коробки и вес. Вес по весам — если взвешиваете. → «📦 Упакована».

**3. Склад и адрес.** «Переместить» → «Склад ГП →» → «Подтвердить перемещение». Отвезите паллету → вкладка «📍 Разместить» → отсканируйте табличку адреса (адрес подставится сам) → «📍 Разместить».

«⚠ Паллета не упакована» при передаче на склад — «Отмена» и сначала шаг 2.

## Исправления, брак, список, учебные паллеты

**Брак при упаковке:** вкладка «Брак» → количество, причина → «Провести брак». Делайте до «📦 Упакована»; если уже упаковали — после брака нажмите «📦 Упакована» ещё раз.

**На паллете другое количество, артикул или цвет (ошибка ввода, а не брак):** вкладка **«✎ Исправить»** → причина → «Сохранить исправление». Если паллета уже была упакована — отметьте упаковку заново.

**Отменить своё действие:** «🕘 Мои действия» → «↩ Отменить» или «✎ Исправить» (24 часа).

**Список «На участке»:** сверху свежие. Цвет: зелёный — до 2 ч, серый — до суток, оранжевый — больше суток, красный — залежалась. Остатки по участкам — «📊 Отчёты» → «Шт на этапах».

**🎓 Учебные паллеты** (жёлтая плашка) — для тренировки, в учёт и на склад не идут.

## Ошибки и что делать

| Что видите | Что делать |
| --- | --- |
| Упаковывать можно на участке упаковки или на складе ГП | Паллета ещё не принята — сначала «✓ Принять на «Упаковка»». |
| ⚠ Паллета в зоне набора прочности всего … | «Отмена», ждите или спросите мастера. |
| ⚠ Паллета не упакована | «Отмена», сначала «📦 Упакована». |
| Справочник адресов пуст | Скажите мастеру; на склад передать всё равно можно. |
| На паллете меньше изделий | При приёме — факт и причина; уже приняли — «Брак»; изделий нет физически — мастеру. |
| ТСД: после оранжевой кнопки ничего | Коснитесь экрана и повторите. Не помогло — мастеру. |
| Неверный PIN | Введите заново; забыли — мастер выдаст новый. |
| Нет связи, кнопка крутится | Не нажимайте повторно. Проверьте Wi-Fi, потом отсканируйте паллету ещё раз. |
