# Инструкция мастера (RU)

Мастер ведёт учёт в Google Таблице своего цеха: сменное задание по постам, работники и PIN, этикетки, контроль и исправления. Инструкция одна для всех цехов; меню Таблицы называется «Меню Цех N».

## Роль мастера и что нового

Маршрут паллеты: Заливка → Распалубка → Распиловка → Покраска → Зона набора прочности → Упаковка → Склад ГП. На каждом участке паллету принимает тот, кто там работает.

Новое в приложении и Таблице:

- **Посты заливки** — в сменном задании колонка «Пост», заливщик видит позиции своего поста.
- **Рабочие сутки с 06:00** — заливка после полуночи идёт в задание предыдущего дня.
- **«✎ Исправить»** — любой работник на любом участке исправляет количество, артикул, цвет, заказ с причиной; остатки и задание пересчитываются.
- **ТСД Mertech** — скан оранжевой кнопкой.
- **Список «На участке»** — сначала свежие, цвет по времени на участке.
- **Этикетки на Xprinter XP-365B** и своя нумерация цеха (в Цехе 2 номера начинаются с PL-2000…, чтобы не совпадать с другими цехами).
- **🎓 Учебные паллеты** — после «Начать учёт заново» старые паллеты для тренировки, в учёт не идут.

## Приложение на телефонах и ТСД

**Телефон рабочего:**

1. «Меню Цех N» → «📱 Приложение с камерой» — ссылка и QR-код.
2. Открыть ссылку в Chrome → ⋮ → «Добавить на главный экран».
3. Рабочий выбирает «Цех ▾», входит по PIN, выбирает участок. Проверьте участок — от него зависит кнопка «✓ Принять».

**ТСД Mertech (один раз):**

1. Приложение **Barcode Utility** → Function Settings → режим вывода **«Simulate keystroke»** (эмуляция клавиатуры), суффикс **Enter**.
2. Установить приложение как на телефон.
3. В профиле (нажать имя вверху) поставить галочку **«Это ТСД со встроенным сканером»**.
4. Проверка: оранжевая кнопка на этикетку — открывается карточка паллеты.

**Что смотреть мастеру в приложении:** «📊 Отчёты» → «Задание заливки» (с итогами по постам) и «Шт на этапах»; скан любой паллеты — история: кто, когда, что делал.

## Сменное задание: посты, рабочие сутки

Открыть: «Меню Цех N» → **«📋 Сменное задание: открыть»**.

| Колонка | Что вписать |
| --- | --- |
| Дата | Дата рабочих суток |
| № заказа, Контрагент | Из заказа |
| Артикул | Выбрать из списка |
| Цвет | Цвет / пигмент |
| **План форм** (жёлтая) | Сколько форм залить |
| Комментарий | По желанию |
| **Пост** (последняя колонка) | Пост 1 / 2 / 3. **Пусто — позицию видят все посты** |

**Правила:**

- Одна строка = заказ + артикул + цвет + пост. Чтобы разделить позицию между постами, сделайте две строки с разными постами и разделите план.
- **Рабочие сутки начинаются в 06:00.** Заливка после 00:00 до 06:00 засчитывается в задание **предыдущего** дня. Час меняется в «Настройки» → «Начало рабочих суток, ч».
- Названия постов — в «Настройки» → «Посты заливки» (через запятую).
- После правки задания скажите заливщикам нажать **⟳** в приложении.
- Фильтры меню: «сегодня», «завтра», «все» — для быстрого просмотра.
- Факт и «Выполнено» не трогайте — они считаются сами.

## Контроль, отчёты, исправления

- **Факт / Выполнено** в задании заполняются автоматически по сканам заливщиков. Заливка без задания попадает в строки «вне задания» — проверьте их в конце смены.
- Остатки по участкам и дашборды обновляются сами. Если цифры выглядят странно — «Меню Цех N» → **«🔄 Пересчитать всё»**.
- Рабочие могут исправить данные паллеты кнопкой **«✎ Исправить»** на любом этапе. Каждое исправление пишется в историю как **«Инвентаризация ±»** с именем работника — проверяйте такие строки.
- Ошибочную операцию рабочий отменяет сам: «Мои действия» → отменить.
- Паллету залили ошибочно → выделите строку в «Паллеты» → **«↩ Паллеты: сбросить выделенные»**.
- Ранний выпуск из зоны набора прочности — только решение мастера.
- Если в старых записях ночная заливка попала не в те сутки — **«Рабочие сутки: применить к старым записям»** (можно запускать повторно, дважды не сдвигает).

## Пользователи, этикетки XP-365B, учебные паллеты

**Пользователи.** «Меню Цех N» → добавить пользователя → система даст PIN, передайте его рабочему лично. Забыл PIN — выдайте новый. Уволился — в колонке «Активен» поставьте **Нет** (строку не удаляйте — история сохранится).

**Этикетки на Xprinter XP-365B:**

1. «🏷 QR-этикетки: напечатать новые…» → укажите количество.
2. Нажмите **«🖨 Открыть для печати на XP-365B»**.
3. В окне печати: принтер XP-365B, размер бумаги = размер этикетки (Ш×В), поля **нет**, масштаб **100%**, колонтитулы **выключены**.
4. Размер этикетки меняется: «🏷 Этикетки: размер для принтера». Нумерация цеха: «🏷 Этикетки: своя нумерация цеха».
5. Перепечатать испорченную: выделите строки в «Паллеты» → перепечать выделенных. Таблички адресов склада печатаются там же.

**Учёт заново и обучение:**

- **«🧹 Начать учёт заново»** — все старые данные уходят в архивную таблицу на Google Диске, старые паллеты становятся **учебными** (метка «🎓 УЧЕБНАЯ», в учёт не идут). Делается один раз перед стартом нового учёта.
- **«🎓 Учебные паллеты: завершить обучение»** — когда все научились, учебные паллеты убираются.
- **«🗂 Вкладки: упорядочить»** — нужные вкладки слева, служебные скрыты. «показать все» — если нужна скрытая.
- В ячейке **E11** на листе «Настройки» должен стоять код цеха (c2 для Цеха 2, c3 для Цеха 3). Не меняйте его.

## Если что-то пошло не так

| Что случилось | Что делать |
| --- | --- |
| У заливщика «Нет задания на сегодня» | Проверьте дату в задании (помните про 06:00). Пусть нажмёт ⟳ |
| На посту не видно позиции | В колонке «Пост» стоит другой пост. Исправьте или оставьте пустым |
| «Нет «Шт в форме»» | В справочнике артикулов заполните «Шт в форме» для этого артикула |
| Нет связи в приложении | Проверьте Wi-Fi / интернет. Операцию повторить после появления связи |
| В «Лог\_форм» строка «ОШИБКА» | Прочитайте текст ошибки, исправьте данные, при необходимости — «🔄 Пересчитать всё» |
| Не появляется «Меню Цех N» | Обновите страницу таблицы, подождите 10–20 секунд |
| ТСД не вводит код сам | Barcode Utility → «Simulate keystroke» + суффикс Enter; в профиле галочка «Это ТСД» |
| Страница этикеток — ошибка 404 | На GitHub нет файла **labels.html** (имя строго с .html) |
| «Не указан код цеха» | На листе «Настройки» в E11 впишите код цеха (c2 / c3) |

> **Главное правило:** не правьте руками листы «Движение», «Паллеты», «Остатки» и колонки факта в задании. Все исправления — через приложение или меню.
