# Документация БМ — приложение инструкций и регламентов

Работник сканирует QR-код → открывается приложение → выбирает язык (Русский / Тоҷикӣ / O'zbekcha) → выбирает инструкцию → она открывается на выбранном языке.
Если QR-код висит у конкретного рабочего места (например, «Распалубщик»), после выбора языка сразу открывается эта инструкция.

## Что лежит в папке

```
BM_docs/
├── index.html          — само приложение (не трогать без необходимости)
├── catalog.json        — СПИСОК ДОКУМЕНТОВ: названия на 3 языках и пути к файлам
├── qr.html             — страница печати QR-кодов (общий + на каждый документ)
├── docs/
│   ├── ru/             — документы на русском
│   │   ├── master.md           Мастер
│   │   ├── zalivshik.md        Заливщик
│   │   ├── raspalubshik.md     Распалубщик
│   │   ├── upakovshik.md       Упаковщик
│   │   └── reglament-obrazec.md  Регламент участка «Образец» (только RU)
│   ├── tj/             — те же инструкции на таджикском
│   └── uz/             — те же инструкции на узбекском
├── assets/             — библиотеки и значок (работают без интернета)
├── manifest.json, sw.js — значок на экране телефона и офлайн-копия
└── README.md           — эта памятка
```

Правило простое: **один документ = один файл .md в папке своего языка + одна запись в catalog.json.**
Имя файла одинаковое во всех языках (`docs/ru/master.md`, `docs/tj/master.md`, `docs/uz/master.md`).

## Как опубликовать (GitHub Pages, по шагам)

Так же, как приложение учёта, только в отдельном репозитории.

1. Зайдите на github.com под аккаунтом **ziasmachinery-blip** → кнопка **New** (новый репозиторий).
2. Имя репозитория: **bm-docs**. Тип: **Public** (GitHub Pages для приватных репозиториев на бесплатном тарифе не работает). Нажмите **Create repository**.
3. На странице репозитория: **Add file → Upload files** → перетащите **всё содержимое** папки `BM_docs` (не саму папку, а то, что внутри: index.html, catalog.json, папки docs, assets и т. д.) → **Commit changes**.
4. **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → **Save**.
5. Через 1–2 минуты сайт откроется по адресу:
   **https://ziasmachinery-blip.github.io/bm-docs/**
6. Откройте на компьютере **https://ziasmachinery-blip.github.io/bm-docs/qr.html** → **Печать**. Общий QR — на доску у входа в цех, QR ролей — на рабочие места.

Проверка: отсканируйте любой QR телефоном → должен появиться выбор языка.

> Если позже приложение переедет на сервер цеха: положите эту же папку на сервер и откройте `qr.html` уже с сервера — QR-коды сами построятся под новый адрес (адрес также можно вписать вручную в поле вверху страницы печати).

## Как обновить инструкцию

1. Отредактируйте нужный файл `.md` (например, `docs/tj/master.md`).
2. В `catalog.json` у этого документа поменяйте `"version"` (например, на `"03.11.2026 · 25"`) — так телефоны гарантированно скачают новую версию.
3. Загрузите изменённые файлы на GitHub (Add file → Upload files, с заменой).

QR-коды перепечатывать **не нужно** — они ведут на приложение, а не на конкретную версию.

## Как добавить новый документ

1. Положите файлы: `docs/ru/новый.md` (и при наличии `docs/tj/новый.md`, `docs/uz/новый.md`).
2. Добавьте запись в `catalog.json` в список `"documents"`:

```json
{
  "id": "novyi",
  "section": "reglaments",
  "icon": "doc",
  "title":    { "ru": "Название", "tj": "Ном", "uz": "Nomi" },
  "subtitle": { "ru": "О чём документ", "tj": "…", "uz": "…" },
  "files":    { "ru": "docs/ru/novyi.md" },
  "version": "1.0"
}
```

- `id` — латиницей, без пробелов; он же попадает в QR-код (`?doc=novyi`).
- `section` — `roles` (инструкции по ролям) или `reglaments` (регламенты). Можно добавить свой раздел в `"sections"`.
- `icon` — `clipboard`, `bucket`, `layers`, `box`, `palette` или `doc`.
- Если перевода нет — просто не указывайте язык в `files`: приложение покажет русскую версию с пометкой «Только на русском» на языке работника.

3. Откройте `qr.html` и распечатайте QR нового документа.

## Ссылки для QR вручную

- Общий: `https://ziasmachinery-blip.github.io/bm-docs/`
